SOUND WAVE — LOCAL MUSIC STREAMING PLATFORM
===============================================
Open index.html with VS Code Live Server.

Included:
- 30 separate MP3 files
- HTML/CSS/JavaScript only
- Full HTML5 playback of every included MP3
- Play/pause, next, previous, seek, volume
- Shuffle and repeat
- Like button
- Search by title/genre
- Library and playlist filters
- Responsive Spotify-inspired interface
- No backend or external music service required

The 30 MP3s are original synthetic demo tracks generated for this project; they are not recordings of commercial artists.
